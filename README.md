# Online Shoppers Purchasing Intention

Построение модели бинарной классификации, предсказывающая, завершится ли сессия пользователя покупкой.

---

## Данные

Для решения задачи Был выбран датасет [Online Shoppers Purchasing Intention](https://www.kaggle.com/datasets/imakash3011/online-shoppers-purchasing-intention-dataset).  

Данные включают:
- 12,330 сессий  
- 17 признаков (числовые, категориальные и булевые)  
- Revenue - целевая переменная

Дисбаланс классов ~5.5 к 1

## Проверенные гипотезы
1. Нормализация признаков логистической регресии улучшит f1 не менее чем на 0.1
2. Дерево решений покажет f1 выше, чем логистическая регрессия, как минимум на 0.05
3. Оптимизация параметров RandomForest через GridSearch незначительно улучшит f1 модели (не более чем на 0.05)
4. Ограничение сложности дерева решений уменьшит переобучение модели.
5. Отбор 10 лучших признаков через SelectKBest незначительно ухудшит f1 логистической регрессии
6. Среди первых пяти лучших признаков у логистической регрессии будут значения из TrafficType и Month
