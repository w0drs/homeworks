# Porto Seguro's Safe Driver Prediction

**Ссылка:** [Porto Seguro's Safe Driver Prediction](https://www.kaggle.com/competitions/porto-seguro-safe-driver-prediction)
**Результат:** 0.28367 Gini  
**Место:** Примерно 1788. Это соревнование завершено (9 лет назад)

---

## Краткое описание подхода

### Baseline (0.19)
- Random Forest с One-Hot Encoding признаками
- `class_weight='balanced'` для учёта дисбаланса классов

### Улучшения
1. **LightGBM + индикаторы пропусков** (0.23)  
   - Заменил RF на бустинг, добавил признаки `_is_missing` для -1

2. **Подбор параметров LightGBM вручную и с RandomizedSearch**  
   - Результат вручную: CV 0.28, LB 0.16 - переобучение
   - RandomizedSearch: 0.235 LB

3. **CatBoost** (0.277)  
   - Устойчив к переобучению, не требует подбора `scale_pos_weight`

4. **Стэкинг** (0.278)  
   - Объединил LGB + CatBoost + RF через Ridge

5. **Isolation Forest** (0.279)  
   - Добавил признак аномалии

6. **XGBoost в стэкинг + удаление шумных признаков** (0.28367)  
   - Убрал `ps_calc_*`, `ps_car_03_cat`, `ps_car_05_cat` и др.

### Финальное решение (0.28367)
- **Модели:** LightGBM + CatBoost + Random Forest + XGBoost
- **Стэкинг:** Ridge на предсказаниях моделей
- **Признаки:** удалены шумные, one-hot-encoding, добавлен Isolation Forest

---

## Что сработало лучше всего

- **CatBoost** - дал основной скачок (0.23 -> 0.277)
- **Стэкинг** - объединение 4 моделей дало +0.006
- **Удаление шумных признаков** - `ps_calc_*` и признаки с >40% пропусков
- **Isolation Forest** - признак аномалии дал +0.001

---

## Что не сработало

- **Ручной подбор параметров LightGBM** - переобучение (CV=0.28, LB=0.16)
- **Признаки** `is_new_driver`, `age_squared` - без изменений

---

## Итог

Лучший результат был достигнут стэкингом 4 моделей с удалением шумных признаков. Основной прирост дал переход на CatBoost и удаление признаков с высоким процентом пропусков.
